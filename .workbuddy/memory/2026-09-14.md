### BUG：npm start 报 `The required package expo-asset cannot be found`
- 根因：首次 `npm install` 被中断（卡 36 分钟后 kill），依赖树不全；Expo SDK 52 的运行时依赖 `expo-asset ~11.0.5` / `expo-font ~13.0.4` / `expo-keep-awake ~14.0.3` 三个都没装上（已装：status-bar/sharing/clipboard/constants/linking/file-system/router/sqlite/modules-core/modules-autolinking）。
- 修复：把这三个版本写入 `package.json` dependencies（版本取自 `node_modules/expo/package.json` 的 dependencies 段），用户在本机终端跑 `npm install --registry=https://registry.npmmirror.com` 补齐。
- 定位方法：Glob `node_modules/expo-*/package.json` 列出已装包 → Grep `node_modules/expo/package.json` 的 dependencies 段比对版本。

### BUG：Expo Go `Project is incompatible ... SDK 57 vs SDK 52`
- 原因：手机上装的 Expo Go 是最新（SDK 57），项目 `expo ~52.0.0`。Expo Go 与项目 SDK 必须严格一致。
- 官方结论（docs.expo.dev/troubleshooting/expo-go-version-mismatch，重要，跨会话复用）：
  - **Android 真机/模拟器、iOS 模拟器：可装旧版** → https://expo.dev/go 选 SDK 版本下载；或 `npx expo-go download android 52` / `npx expo-go url android 52 --json`。
  - **iOS 真机：SDK 53 及更早版本无法安装旧版 Expo Go**（Apple 政策，不能侧载降级）。iPhone 只能：升级项目 SDK / 换 Android / 用 iOS 模拟器 / 做 dev build（SDK 54+ 才可用 `eas go` + TestFlight）。
  - Android 装旧版前需先卸载现有 Expo Go（同为 host.exp.exponent 包名，不能并存）。
- 用户选择：手机端降级装 SDK 52 的 Expo Go（不动代码、不升级项目）。
